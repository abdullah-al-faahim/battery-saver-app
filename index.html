Setup

Ready in two minutes

Install it, allow one permission, and you're done. 1-tap stop is optional.

Install

Everyone does this.

  1. Download the APKTap the green button on your phone.
  2. Open BatterySaver.apkIf asked, allow your browser to install unknown apps.
  3. Allow Usage accessIn the app, tap Allow on the yellow banner and switch Battery Saver on.
  4. Tick apps → Stop selectedBattery Saver opens each app's page; tap Force stop.
Play Protect warning? Tap More details → Install anyway. Google shows this for every app that isn't from the Play Store.

Switch greyed out? Settings → Apps → Battery Saver → ⋮ → Allow restricted settings, then try again.

1-tap stop Optional

Stop the whole list instantly, with Shizuku.

  1. Install ShizukuFree and open source, on the Play Store.
  2. Turn on Developer optionsSettings → About phone → tap Build number 7 times.
  3. Turn on Wireless debuggingIn Developer options.
  4. Start ShizukuOpen Shizuku → Start via Wireless debugging → Pairing, and enter the code.
  5. Allow in Battery SaverTap Allow on the 1-tap stop banner. Usage access turns on automatically.
After a restart, open Shizuku and tap Start again.
FAQ

Questions

Will I still get WhatsApp or Messenger messages?

Not while that app is stopped. Notifications come back as soon as you open it. Leave apps you need instant messages from off your stop list.

Are the battery numbers exact?

They're estimates. Android only gives exact per-app battery percentages to the phone maker's own system apps. Battery Saver uses screen time and background-service time, the two biggest causes of drain, to rank apps.

What is Shizuku, and is it safe?

Shizuku is a well-known open-source tool that you start yourself through Wireless debugging. It lets apps you approve run the commands a computer could run over USB. Battery Saver uses it only to force-stop apps, apply Deep restrict, and switch on its own Usage access.

Does it need root?

No. It works on Samsung, Xiaomi, Realme, Oppo, Vivo, Pixel, Motorola and every other Android 8.0+ phone without root.

Does Battery Saver drain battery itself?

No. It has no background service, no scheduled jobs and no notifications. It only works while it's open or when you tap Stop.
